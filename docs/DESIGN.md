# UI 設計說明

記錄無法直接從程式碼推導的 UI 與匯出決策。共用色彩、間距與控制尺寸見 `src/styles/tokens.css` 與 `src/styles/design-system.css`。

## 視覺基調

- 暖紙底、深墨字、細邊框、克制小圓角。
- 角色圖、名稱與 build 為主內容；控制項不搶焦點。
- 每個操作區僅保留一個 primary action；分享、危險與一般操作各有語意色。
- 一般控制高 38px，緊湊控制高 32px；觸控目標至少 44px。
- 桌面 TopBar 各控制位置固定，語系切換與「已複製」狀態不推動其他按鈕。

## 角色卡與設定

- Pool 與 Pool 匯出依序顯示：頭像、名稱、`LV.`、洞悉、共鳴。
- 總覽點洞悉或共鳴只會遞增；降低數值、調等級與塑造在角色設定進行。
- 頭像左上放 Skin、右上放移除，頭像內僅保留塑造標記。
- 共鳴統一使用側視頭部圖示（不用 `R` 或 emoji）。
- 角色設定與「設定預設」共用 stepper、快捷值與洞悉圖示（不用 number input 或 `I0–I3` 文字）。
- 「設定預設」採草稿編輯，按完成才提交；取消、關閉或點外部均捨棄。

## 隊伍

- 固定四隊、每隊四個正式位置；手機以四個隊伍 tab 切換，tab 只顯示隊名。
- 隊名上限 12 字，輸入第 13 字時才顯示提示。
- 空位不重複顯示「空位」文字或換位按鈕。
- 頭像內顯示位置與塑造，右側摘要顯示等級、洞悉、共鳴。
- 同一角色不可在同一隊重複，可跨隊重複。
- 指派角色或心相時，Pool 暫切至「持有」；完成或取消後還原原本的 filter。

## 心相

- 點擊 Pool 卡片持有或升增幅（1–5）；左上 `−` 降增幅，右上 `×` 取消持有。同一心相可跨格／跨隊重複裝備。
- 增幅 1 隱藏 badge；增幅 2–5 於心相圖右下角顯示純數字（總覽與匯出共用）。
- 雙生舞伶可裝備兩個指定心相；先裝「藝術原子能」時，若尚未持有「科學編舞法」，自動持有並裝上。
- 饕餮與貪慾屬升階素材，不進入心相 Pool。

## 響應式、字型與無障礙

- 桌面使用錨點 popover，手機改為 bottom sheet。
- 低頻設定展開時不改變 toolbar 尺寸；空間不足時控制項換行而非壓縮。
- `zh-CN` 套用 SC 字型、`ja-JP` 套用 JP 字型，避免漢字落至錯誤字形。
- 所有 icon button 須具可及名稱，toggle 使用 `aria-pressed`，核心功能不依賴 hover、拖曳或顏色。
- UI 驗收涵蓋 `375 / 640 / 900 / 1440px`，並檢查 keyboard focus、outside click 與 coarse pointer。

## 匯出圖片

- 畫布固定寬 1480px。隊伍沿用首頁 `team-panel` / `team-slot`，Pool 沿用 `char-card` / `psy-card`。
- 僅輸出有角色的隊伍；header 與 section 不顯示數量統計。
- 隊伍心相名稱僅出現於匯出圖：單心相置於圖右，雙心相依裝備順序分兩行。
- `REVERSE: 1999` 與各語系產品名同行且垂直置中。
- 空輸出依所選範圍判定（隊伍看隊伍、Pool 看持有角色與心相、兩者看聯集）；全空時保留 header／footer，中央顯示 Vertin 圖與兩行提示。
- 匯出前等待字型與所有圖片完成載入，所有匯出 `<img>` 使用 `loading="eager"`。
