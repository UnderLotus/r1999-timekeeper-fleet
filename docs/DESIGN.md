# UI 設計說明

這份文件只記錄不容易從 code 看出原因的設計決策。共用色彩、間距與控制尺寸在 `src/styles/tokens.css` 和 `src/styles/design-system.css`。

## 視覺基調

- 暖紙底、深墨字、細邊框與克制的小圓角。
- 角色圖、名稱和 build 是主內容；控制不要搶走視線。
- 一個操作區只留一個 primary action。分享、危險操作與一般操作使用各自的語意色。
- 一般控制高 38px，緊湊控制高 32px；觸控裝置的可點範圍至少 44px。

## 角色卡怎麼操作

- Pool 與 Pool 匯出都依序顯示：頭像、名稱、`LV.`、洞悉與共鳴。
- 總覽點洞悉或共鳴只會增加；降低數值、改等級與塑造放在角色設定裡。
- Skin 在卡片左上，移除在右上。頭像內只留必要的塑造標記。
- 角色設定和「設定預設」使用相同的 stepper、快捷值與洞悉圖示，不用 number input 或 I0–I3 文字。
- 「設定預設」先編輯草稿，按完成才保存；取消、關閉或點外面都不提交。

## 隊伍怎麼排

- 固定四隊，每隊四個正式位置；第四格不是替補。
- 手機用四個隊伍 tab 切換，tab 只顯示隊名。
- 隊名最多 12 字，平時不顯示計數；輸入第 13 字時才提示。
- 空位置不要重複寫「空位」或顯示換位按鈕。
- 頭像內放位置與塑造；等級、洞悉與共鳴放在右側摘要。
- 同一角色不能在同一隊重複，但可出現在不同隊伍。
- 指派角色或心相時，Pool 暫時切到「持有」；完成或取消後回到使用者原本的 filter。

## 心相怎麼操作

- 心相記錄的是持有與增幅 1–5，不是可消耗張數。同一心相可以重複裝在同隊或不同隊。
- 點 Pool 卡片會持有或提高增幅；左上 `−` 降低，右上 `×` 取消持有。
- 增幅 1 不顯示 badge；增幅 2–5 的純數字放在心相圖右下角。總覽與匯出共用這個位置。
- 雙生舞伶可以裝兩個指定心相。先裝「藝術原子能」時，若尚未持有「科學編舞法」，會自動持有並裝上。
- 饕餮與貪慾是升階素材，不出現在心相 Pool。

## Popover 與手機版

- 桌面使用靠近觸發點的 popover；手機改成 bottom sheet。
- 低頻設定展開時不能改變整條 toolbar 的尺寸。
- 空間不足時把控制分行，不要把按鈕壓成難點的小方塊。
- `zh-CN` 使用 SC 字型，`ja-JP` 使用 JP 字型，避免漢字落到錯誤的區域字形。
- 所有 icon button 都要有名稱；toggle 使用 `aria-pressed`；功能不能只靠 hover、拖曳或顏色。

## 匯出圖片

- 畫布固定 1480px。隊伍沿用首頁 `team-panel` / `team-slot`；Pool 沿用 `char-card` / `psy-card`，不要維護第二套卡片比例。
- 只輸出有角色的隊伍。header 與 section 不顯示持有數、隊伍數或 `2/4`。
- 隊伍中的心相名稱只出現在匯出圖：單心相顯示在圖右側；雙心相依裝備順序顯示兩行。首頁隊伍不顯示名稱。
- `REVERSE: 1999` 與各語系產品名保持同一行並垂直置中。
- 空輸出依使用者選的範圍判斷：隊伍只看隊伍，Pool 只看持有角色與心相，兩者模式看聯集。完全沒有內容時保留 header / footer，中間顯示 Vertin 圖與兩行提示。
- 匯出前會等待字型與所有圖片完成載入；圖片必須使用 eager loading。

## 幾個容易做歪的地方

- Future Sight 關閉只隱藏內容，不清資料。
- 分享網址先進入可編輯 Preview，不直接覆寫本機。匯出與再次分享都使用目前正在看的 Preview。
- 共鳴一律使用側視頭部圖示，不用 `R`、emoji 或另一套圖。
- 桌面 TopBar 各控制有固定位置；語言和「已複製」文案改變時不應推動其他按鈕。
- 驗收至少看 375、640、900、1440px，並確認 keyboard focus、outside click 和 coarse pointer。
