# r1999-timekeeper-fleet

『リバース：1999』のキャラ、心相、チーム編成を整理するための小さなツール

**[English](README.md) · [繁體中文](README_tw.md)**

---

## 簡単な使い方

### キャラ

まず「キャラ」タブを開き、キャラをクリックすると所持状態になります。

所持済みのキャラでは、次の操作ができます。

- もう一度キャラをクリックすると詳細設定が開き、レベル、洞察、共鳴、塑造などを調整できます
- アイコン下部の洞察と共鳴をクリックすると、すばやく +1 できます
- 衣装アイコンから衣装を切り替えられます
- 右上の × で未所持に戻せます

所持キャラをまとめて登録する場合は、先に「デフォルト設定」で多くのキャラに共通する状態を設定しておくのがおすすめです。例：洞察3、最大レベル、共鳴10、塑造0、洞察衣装

検索はすべての対応言語に対応しています。

### 心相

心相もクリックすると所持状態になります。

所持済みの心相では、次の操作ができます。

- もう一度クリックすると増幅が1段階上がり、最大5まで設定できます
- 左上の − で増幅を下げられます
- 右上の × で未所持に戻せます

ほとんどの心相は1枚だけ所持するため、複数枚の管理機能は省いています。
また、ベテランプレイヤーはほとんどの心相を所持していることが多いため、「デフォルト設定」ですべてを所持状態にしてから、未所持の心相だけを外すこともできます。

### チーム

空いているキャラ枠をクリックするとキャラを選択でき、心相枠をクリックすると心相を変更できます。チーム名は自由に設定でき、上限は12文字です。

## 共有URLの仕組み

今回の最も重要な機能更新です。

共有URLからサイトを開くと「プレビューモード」になります。自分で保存したリンクであれば、そのままインポートして現在のデータを置き換えられます。

ほかの人のチーム編成を手伝う場合は、次のように使えます。

- プレビューモードのまま直接操作・編集する
- 編集結果をリンクまたは画像として出力し、相手に送り返す
- 「自分のデータに戻る」を選び、相手のデータを保存せずに終了する

ほかの人から共有されたチームURLも、自分のデータが上書きされる心配なく、安心して開いて編集できます。

共有内容に未来視の対象となる未実装コンテンツが含まれる場合は通知が表示され、表示やインポート方法を選択できます。

## 未来視

サーバーごとに実装状況が異なるため、サイトでは海外版の進行状況を標準で表示します。必要に応じて未来視を有効にできます。

---

## 画像出力

画像出力では、次の3種類を選択できます。

- チームのみ
- キャラ Pool のみ
- チーム + キャラ Pool

出力内容は、常に「現在表示しているワークスペース」が基準です。
ほかの人の共有プレビューを表示している場合は、そのプレビュー内容が出力されます。

## 開発

```bash
npm ci
npm run dev
```

コミット前に実行：

```bash
npm test
npm run build
```

キャラ、心相、名称、実装状況、画像を更新する場合：

```bash
npm run sync
```

GitHub Pages の base path は `/r1999-timekeeper-fleet/` です。

データソース、同期フロー、個別の更新コマンドについては [`docs/pipeline.md`](docs/pipeline.md) を参照してください。

## データソース

キャラ、名称、実装状況、画像は主に以下の情報源をもとに整理しています。

- [Reverse-1999-CN-Asset](https://github.com/myssal/Reverse-1999-CN-Asset) — 中国版のキャラ / 衣装 / 心相の構成とオリジナル素材
- [re1999-data-global](https://github.com/St-Pavlov-Foundation/re1999-data-global) — Global データ、各言語の名称、実装状況の判定
- [灰機 Wiki](https://res1999.huijiwiki.com) — キャラの並び順と補足データ
- [Kornblume](https://github.com/windbow27/kornblume) — 並び順 / 名称の fallback
- [wikiru](https://reverse1999.wikiru.jp) と [Reverse: 1999 Fandom Wiki](https://reverse1999.fandom.com) — 上流データに不足がある場合の名称補足

ゲーム素材の著作権は **Bluepoch Co., Ltd.（深藍互動）** に帰属します。本プロジェクトは非公式のファン向けツールです。
