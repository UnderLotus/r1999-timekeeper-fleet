# r1999-timekeeper-fleet

整理《重返未來：1999》角色、心相和隊伍配置的小工具

**[English](README.md)**

---

## 簡易適用教學

### 角色

先來到角色分頁，點一下角色就可以將角色變為持有狀態

角色持有之後：

- 再點一下角色會出現完整設定，調整等級、洞悉、共鳴、塑造
- 頭像下方上的洞悉、共鳴點擊一下也可以快速 +1
- 衣服 Icon 可以切換 Skin
- 右上角的 × 可以取消持有

如果你準備要登記箱子裡所有角色，建議先使用"設定預設"，將你角色最多的狀態設定為預設，例如：洞悉3、滿等、共鳴10、零塑、洞悉 Skin

搜尋一樣支援所有語言的搜尋

### 心相

心相一樣是點一下就會變成持有

心相持有之後：

- 再點一下可以往上加疊影，最高 5
- 左上角的 − 用來降疊影
- 右上角的 × 用來取消持有

因為絕大多數心相都只有一張，因此這裡省去了管理複數心相的功能。

### 隊伍

點擊角色空格可以選角色、點擊心相空格可以換心相，隊伍可以自由取名，上限12個字

## 分享網址運作

本次最重要的功能更新

當點擊分享網址進入網站時，會進入"預覽狀態"，此時若這是你自己儲存的連結，你可以直接選擇匯入並覆蓋資料。

但若假設你是在幫忙別人給予配隊建議，你可以：

- 直接在預覽狀態操作、修改
- 在預覽狀態將修改完的成果匯出成連結或圖片，貼回給另一個人
- 選擇"回到我的資料"，乾淨退出，不儲存別人的資料

所以收到別人的隊伍網址時，可以放心打開看看、改一改，不用先擔心自己的配置被洗掉

而分享內容有未來視內容時也會提示你，可以自行選擇是否匯入

## 未來視

由於各伺服器進度不同，網站預設顯示海外伺服器進度，有需要的使用者可以自行開啟未來視

---

## 匯出圖片

本次匯出圖片新增三種格式：

- 只匯出隊伍
- 只匯出角色池
- 隊伍 + 角色池

匯出永遠以「你現在正在看的工作區」為準。
也就是說，如果你正在看別人的分享預覽，匯出的就是那份預覽

## 開發

```bash
npm ci
npm run dev
```

提交前跑：

```bash
npm test
npm run build
```

要更新角色、心相、名稱、實裝狀態和圖片：

```bash
npm run sync
```

GitHub Pages 的 base path 是 `/r1999-timekeeper-fleet/`。

資料來源、同步流程和個別更新指令請看 [`docs/pipeline.md`](docs/pipeline.md)。
